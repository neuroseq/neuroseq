# Input Design and Readout Analysis

This section covers the shared workflow for designing stimulation and analyzing
network responses, across simulations, neuromorphic hardware, and biological
experiments. For model execution and device connections, see
[Neural Networks](../Neural%20Networks/overview.md).

## Input design

- [Stimulation editor and static input](static_input_design.md): create and edit
  stimulation arrays, generate patterns, and repeat protocols.
- [Design dynamic input](stdp_synaptic_tuning.md): use response measurements to
  guide subsequent stimulation with STDP synaptic tuning.
- [Export patch-clamp stimuli](export_patch_clamp_stimuli.md): prepare protocols
  for external acquisition software.

## Readout analysis

- [Experiments](experiments.md): organize recordings and generate synthetic data.
- [Import Igor2 waves](importing_igor2_waves.md) and
  [imaging data](importing_imaging_data.md): bring external recordings into a project.
- [Analysis tools and plugins](analysis_and_plugins.md): measure selected data
  and run built-in or custom analyses.
- [Connecting simulations and experiments](simulations_and_experiments.md):
  manage project data and compare simulated and recorded responses.
