# Readout overview

Readout brings a network's observed output into the project as data groups
(traces, spikes, synapses, imaging), matched to the same neuron IDs as the
input arrays.

| Page                                    | Covers                                                                              |
| --------------------------------------- | ----------------------------------------------------------------------------------- |
| [Experiments](experiments.md)           | Manage data groups, generate synthetic data.                                        |
| [Imaging data](imaging_data.md)         | Cell segmentation, neuron ID mapping, traces from raw TIFFs or precomputed outputs. |
| [Patch-clamp data](patch_clamp_data.md) | Command waveforms and recordings from `.ibw`, `.pxp`, `.csv` and `.txt` files.      |

To analyse the data, see [Data analysis](../data_analysis/analysis.md).
