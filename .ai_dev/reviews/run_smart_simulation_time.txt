Almost there. `Project.tile_stim_arrays_to_length`, the
`getSimulationTime` default-kwarg extension, and the GUI dispatch swap
(pad → tile, with cumulative offset) all match the handoff exactly and
work correctly. The new dispatch tests are good.

One MUST-FIX: the `_meaningful_row_count` algorithm trims the trailing
event of the default Für Elise stim because all 10 samples of the final
pitch-5 event are identical rows. The user's stated expectation in the
handoff conversation was "in the elise case, 1.92s", but the current
implementation suggests 1.91 s. The handoff specced the simpler
"trim-any-constant-tail" algorithm, which I now see was wrong for this
use case — the spec is the source of the bug.

The fix is to require the trailing-tail row to be UNIFORM across
channels (all elements equal) before treating it as rest. That keeps
the "trim trailing rest" behaviour for genuine all-rest tails (`np.pad`
zeros, or all-channels-at-E_l) while preserving the last event of any
multi-channel signal pattern where one channel is active and the
others are not.

Verified locally:

    from neuroseq.example_projects import _build_fuer_elise_pattern
    from neuroseq.project import _meaningful_row_count
    _meaningful_row_count(_build_fuer_elise_pattern())  # → 1910, want 1920


MUST-FIX
--------

1.  src/neuroseq/project.py:53-69 — `_meaningful_row_count` over-trims
    multi-channel patterns whose last event spans multiple identical rows.

    Current:

        def _meaningful_row_count(values: np.ndarray) -> int:
            """Return n such that values[n:] is a constant tail."""
            n_rows = int(values.shape[0])
            if n_rows == 0:
                return 0
            tail = values[-1]
            tail_len = 0
            for i in range(n_rows - 1, -1, -1):
                if np.array_equal(values[i], tail):
                    tail_len += 1
                    continue
                break
            if tail_len == n_rows:
                return 0
            if tail_len == 1:
                return n_rows
            return n_rows - tail_len

    Trace for Für Elise default (`(1920, 13)`): row 1919 ≡ rows 1910-1918
    (the 10 ms of pitch 5 active that closes each cycle). Tail_len = 10.
    Result: 1920 − 10 = 1910 → suggested 1.91 s.

    Replace with a uniform-tail guard before the trimming loop. A multi-
    channel row whose elements are NOT all equal is signal, not rest, and
    should never be treated as a tail:

        def _meaningful_row_count(values: np.ndarray) -> int:
            """Return n such that values[n:] is a uniform-and-constant tail.

            A "tail" must satisfy BOTH:
              * the tail row is uniform across channels (all elements equal),
                so it represents "every neuron at the same rest value", and
              * the row is repeated identically from some index onward.

            Multi-channel patterns whose last event has only one channel
            active are NOT uniform and are left intact.
            """
            n_rows = int(values.shape[0])
            if n_rows == 0:
                return 0
            tail = values[-1]
            # Non-uniform last row = signal, not rest. Don't trim.
            if tail.size > 0 and not np.all(tail == tail.flat[0]):
                return n_rows
            tail_len = 0
            for i in range(n_rows - 1, -1, -1):
                if np.array_equal(values[i], tail):
                    tail_len += 1
                    continue
                break
            if tail_len == n_rows:
                return 0
            return n_rows - tail_len

    The `if tail_len == 1: return n_rows` special case Codex added is no
    longer needed — the uniform check covers the same class of cases
    more cleanly. Remove it.
