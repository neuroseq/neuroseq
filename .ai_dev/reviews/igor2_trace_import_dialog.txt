=================================================================
ADDITIONAL TASK — Project-wide canonical dt: keep stim and trace
                  timeline ticks in sync
=================================================================

PROBLEM
-------
Stimuli (`StimArray.dt`) and traces (`TraceData.dt`) currently carry
independent sample intervals.  Both are plotted on the same absolute
time axis (0 … `project.max_time_secs`), but their tick grids are
generated separately in `gridlines.py` using each object's own `dt`.

If a stimulus lives at 1 ms and a trace is imported at 0.5 ms, the
two widgets render ticks at different densities — a vertical line on
the trace widget lands between two ticks on the stim widget.  More
importantly, the stim editor's draw grid is 1 ms wide while the trace
data has twice the resolution; a user drawing a stimulus at 1 ms
resolution cannot match sub-ms trace events.

This disconnect surfaces in three import paths:
  • `IgorImportDialog` — "Adjust NeuroSeq stim grid to source/file grid"
    changes the selected stim array's dt but leaves all traces at their
    existing dt.
  • `IgorTraceImportDialog` — "Adjust NeuroSeq trace grid to source/file
    grid" changes the imported trace's dt but leaves all stim arrays at
    their existing dt.
  • `PatchClampImportDialog` — same issue; traces can land at any dt the
    experimenter recorded at.


DESIGN
------
Introduce a single **project-level canonical dt** (`Project.dt: float`,
default `NEUROSEQ_IGOR_TARGET_DT_SECONDS = 0.001`).

Invariant: every `StimArray.dt` and every `TraceData.dt` in the project
must equal `project.dt`.  Nothing else enforces alignment; the invariant
is maintained at the two mutation points:

  1. Adding a new StimArray or TraceData whose dt differs → remap it to
     `project.dt` before storing, OR change `project.dt` and remap
     everything else.
  2. Calling `update_stim_array_properties` with a new dt (the stim
     editor's "change dt" path) → treat the new dt as the new canonical
     dt and remap all stims and all traces.

The user must be asked before any global remap that touches existing
data — one QMessageBox.question listing what will be remapped and
confirming the new dt.

      def remap_all_data_to_dt(self, new_dt: float) -> None:
          """ZOH-remap every StimArray and every TraceData to new_dt."""
          from neuroseq.importer_igor2 import resample_wave_zero_order_hold
          from neuroseq.stim_timing import remap_stim_values_to_dt

          for stim_array in self.stim_arrays.values():
              if not stim_dt_matches(float(stim_array.dt), new_dt):
                  stim_array.values = remap_stim_values_to_dt(
                      stim_array.values, float(stim_array.dt), new_dt
                  )
                  stim_array.dt = new_dt

          for experiment in self.experiments.values():
              for data in experiment.data:
                  if isinstance(data, TraceData):
                      if not stim_dt_matches(float(data.dt), new_dt):
                          new_rows = [
                              resample_wave_zero_order_hold(
                                  data.traces[i],
                                  source_dt=float(data.dt),
                                  target_dt=new_dt,
                              )
                              for i in range(data.traces.shape[0])
                          ]
                          data.traces = (
                              np.stack(new_rows, axis=0).astype(np.float32, copy=False)
                              if new_rows
                              else np.zeros((0, 0), dtype=np.float32)
                          )
                          data.dt = new_dt

          self.dt = new_dt
          self.update_limits()
