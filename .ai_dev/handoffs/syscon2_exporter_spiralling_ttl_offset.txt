syscon2_exporter_spiralling_ttl_offset — Shift every laser TTL by -1 tick when spiralling is on [IMPLEMENTED]
==============================================================================================================

SysCon v3 in spiralling mode requires the laser TTL pulse to start **one tick before**
the SLM completes its 16.666 ms load (= 32 ticks at 520.8125 µs/tick). The 1-tick
lead compensates for the spiralling hardware's own ~1-tick warm-up: when the SLM
becomes ready at tick 32, the laser is already firing.

Today the exporter emits laser TTL pulses at `adjusted_raw_segment.start_idx` (i.e.
raw sample index + 32 ticks of preblank shift). With spiralling enabled this is one
tick too late.

This handoff adds a `spiralling` flag (UI checkbox, default ON) that subtracts 1 tick
from every laser TTL pulse's start AND end (preserving duration). When the checkbox
is unchecked, the current behavior is unchanged.

The change is intentionally **minimal** — Option B from the design discussion:

  - One TTL per drawn burst (current multi-burst-per-shape behavior preserved).
  - Spiralling ON: pulse_start -= 1, pulse_end -= 1 (uniform shift).
  - Spiralling OFF: no change vs. today.

This is NOT the "one TTL per shape, anchored absolutely to shape_start + 31"
reshaping (Option A) — the user explicitly chose B to keep sub-window burst timing
intact.

            # tick before the SLM load completes (tick 32 of each shape) keeps the
            # active laser edge aligned with SLM-ready. Shift both endpoints so the
            # pulse duration is preserved.

5.  DEFENSIVE EDGE CASE — In practice every pulse interval has
    `start >= _SYSCON2_WINDOW_TICKS == 32` because the preblank-window insertion in
    `_apply_preblank_insertions_to_raw_segments` shifts every raw segment by one
    full SLM window. So `start - 1 >= 31` and `end - 1 > start - 1`. No clamping is
    required. Do NOT add `max(0, ...)` guards — if a pulse ever lands at start=0,
    that means the preblank logic upstream broke, and we'd rather see the negative
    value loudly fail the validator than silently mask the bug. Add a one-line
    comment to that effect next to the list-comprehension.

        def test_export_seq_spiralling_shifts_laser_pulse_one_tick_earlier() -> None:
            values = np.zeros((40, 1), dtype=np.float32)
            values[20:22, 0] = 1.0
            stim_array = StimArray(
                name="stim",
                stim_type=StimType.Excitation,
                values=values,
                units="1",
                dt=_DT_S,
            )

            seq_text_on, report_on = generate_syscon2_sequence_text(
                stim_array,
                _cellpose_result(mapping={0: 0}),
                template_text=_template_header(),
                tick_resolution_us=500,
                active_threshold=0.0,
                binary_intensity=1.0,
                active_laser_wavelength_nm=1100,
                spiralling=True,
            )
            seq_text_off, _ = generate_syscon2_sequence_text(
                stim_array,
                _cellpose_result(mapping={0: 0}),
                template_text=_template_header(),
                tick_resolution_us=500,
                active_threshold=0.0,
                binary_intensity=1.0,
                active_laser_wavelength_nm=1100,
                spiralling=False,
            )

            seq_on = parse_syscon2_seq_text(seq_text_on)
            seq_off = parse_syscon2_seq_text(seq_text_off)

            laser_on = [
                obj for obj in seq_on.objects
                if obj.object_type == "TTLPulse"
                and _timeline_index(obj) == report_on.laser_timeline_index
            ]
            laser_off = [
                obj for obj in seq_off.objects
                if obj.object_type == "TTLPulse"
                and _timeline_index(obj) == report_on.laser_timeline_index
            ]
            assert len(laser_on) == 1
            assert len(laser_off) == 1

            # 1-tick shift = 520.8125 µs
            assert laser_off[0].start_time_us - laser_on[0].start_time_us == pytest.approx(
                _TTL_QUANTUM_US
            )
            # Duration unchanged (TTLPulse repeats field is the duration encoding).
            assert laser_on[0].repeats == laser_off[0].repeats
            # And the TTL Out 1 mirror shifts identically (it shares pulse_intervals).
            ttl_out_1_on = [
                obj for obj in seq_on.objects
                if obj.object_type == "TTLPulse"
                and _timeline_index(obj) == report_on.ttl_out1_timeline_index
            ]
            ttl_out_1_off = [
                obj for obj in seq_off.objects
                if obj.object_type == "TTLPulse"
                and _timeline_index(obj) == report_on.ttl_out1_timeline_index
            ]
            assert ttl_out_1_off[0].start_time_us - ttl_out_1_on[0].start_time_us == pytest.approx(
                _TTL_QUANTUM_US
            )
