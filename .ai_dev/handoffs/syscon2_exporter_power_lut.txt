syscon2_exporter_power_lut — Stimulation power control via project-bundled SysCon .lut tables [IMPLEMENTED]
============================================================================================================

Today the SysCon2 exporter hard-writes `TimelineInfo0_Intensity_0 = "0"` on both
the Shape block and the laser TTLPulse block (exporter_syscon2.py:644 and the
`include_lightsource=True` branch of `_format_ttl_pulse_block`). The user has
confirmed two facts that unlock power control:

  - SysCon reads `Intensity_0` from **both** Shape AND laser TTLPulse to derive
    the actual delivered power.
  - The mW lookup table (`.lut` file, e.g. `20260526_1100-LUT_RAPP.lut`) is
    **enabled by default** in SysCon's hardware configuration — NeuroSeq just
    needs to write the right percent into `Intensity_0`; SysCon does the
    percent→mW translation.

This handoff:

  1. Adds a tiny `.lut` parser + inverse-lookup helper in a new module.
  2. Adds project-bundled per-wavelength LUTs (`Project.power_luts: dict[int, PowerLut]`)
     persisted inside the `.nseq` archive's `project_metadata.json`.
  3. Adds `target_power_mw` and `power_lut` parameters to the exporter; computes
     percent per shape/pulse from `target_mw × window.intensity` (the existing
     "Force binary" checkbox already collapses `window.intensity` to 1.0 when on,
     so unchecked = stim-amplitude multiplier, checked = full target power).
  4. Adds UI: a "Target power (mW)" spinbox and a "Load LUT for *N* nm…" button
     to the stim-generator dialog. Clamps with a warning on saturation.

    from __future__ import annotations

    import re
    from dataclasses import dataclass
    from dataclasses import field


    _LUT_BLOCK_RE = re.compile(r"^\[(_|/_)\]$")
    _KV_RE = re.compile(r"^(\w+)=(.*)$")
    _TUPLE_RE = re.compile(r"^Tuple(\d+)$")


    @dataclass(frozen=True)
    class PowerLut:
        """SysCon .lut: ordered (percent, mW) breakpoints for a single laser channel."""

        description: str
        tuples: tuple[tuple[float, float], ...]  # ((percent, mw), ...), sorted by percent

        @property
        def max_mw(self) -> float:
            return max(mw for _, mw in self.tuples) if self.tuples else 0.0

        def to_serializable(self) -> dict:
            return {
                "description": self.description,
                "tuples": [list(pair) for pair in self.tuples],
            }

        @classmethod
        def from_serializable(cls, data: dict) -> "PowerLut":
            return cls(
                description=str(data.get("description", "")),
                tuples=tuple(
                    (float(p), float(mw)) for p, mw in data.get("tuples", [])
                ),
            )


    def parse_power_lut_text(text: str) -> PowerLut:
        """Parse a SysCon `.lut` file.

        Format (per the user's reference 20260526_1100-LUT_RAPP.lut):

            <hash-line or 'nohash'>
            [_]
            Description=...
            Unit=mW
            Enabled=True|False
            TuplesCount=N
            Tuple0=percent;mW
            Tuple1=percent;mW
            ...
            [/_]

        The hash line and Enabled flag are accepted but ignored — they're
        SysCon-internal. Unit MUST be 'mW' (the only unit we support); raise
        ValueError otherwise.
        """
        description = ""
        tuples_by_idx: dict[int, tuple[float, float]] = {}
        unit = "mW"
        in_block = False

        for raw_line in text.splitlines():
            line = raw_line.strip()
            if not line:
                continue
            if line == "[_]":
                in_block = True
                continue
            if line == "[/_]":
                in_block = False
                continue
            if not in_block:
                continue
            m = _KV_RE.match(line)
            if not m:
                continue
            key, value = m.group(1), m.group(2).strip()
            if key == "Description":
                description = value
            elif key == "Unit":
                unit = value
            elif key.startswith("Tuple"):
                idx_match = _TUPLE_RE.match(key)
                if idx_match is None:
                    continue
                idx = int(idx_match.group(1))
                if ";" not in value:
                    raise ValueError(f"Malformed LUT tuple at {key}: {value!r}")
                percent_str, mw_str = value.split(";", 1)
                tuples_by_idx[idx] = (float(percent_str), float(mw_str))

        if unit != "mW":
            raise ValueError(f"Unsupported LUT unit {unit!r}; only 'mW' is supported")
        if not tuples_by_idx:
            raise ValueError("LUT contains no tuples")

        ordered = tuple(
            tuples_by_idx[idx] for idx in sorted(tuples_by_idx)
        )
        # Tuples in the file are already in percent order; enforce monotonic
        # non-decreasing percent so the inverse lookup is well-defined.
        for prev, curr in zip(ordered, ordered[1:]):
            if curr[0] < prev[0]:
                raise ValueError(
                    f"LUT tuples must be sorted by percent (got {curr[0]} after {prev[0]})"
                )
        return PowerLut(description=description, tuples=ordered)


    def power_lut_mw_to_percent(lut: PowerLut, target_mw: float) -> tuple[float, bool]:
        """Invert ``lut`` at ``target_mw``.

        Returns (percent, saturated). ``saturated`` is True when the requested mW
        exceeds the highest mW reachable by the LUT, in which case ``percent`` is
        clamped to the percent value at that maximum mW.

        Tuples with identical mW values are treated as a flat plateau at the
        SMALLEST percent reaching that mW (so we always pick the most-efficient
        operating point). Negative ``target_mw`` returns 0.0.
        """
        if not lut.tuples:
            raise ValueError("LUT is empty")
        if target_mw <= 0:
            return 0.0, False

        # Find smallest percent whose mW >= target_mw; interpolate within the
        # segment that crosses target_mw.
        prev_pct, prev_mw = lut.tuples[0]
        if prev_mw >= target_mw:
            return float(prev_pct), False
        for pct, mw in lut.tuples[1:]:
            if mw >= target_mw and mw > prev_mw:
                t = (target_mw - prev_mw) / (mw - prev_mw)
                return float(prev_pct + t * (pct - prev_pct)), False
            prev_pct, prev_mw = pct, mw

        # Past the top of the LUT — saturated. Return the percent of the first
        # tuple that reaches max_mw (the most-efficient saturation point).
        max_mw = lut.max_mw
        saturating_pct = next(
            (pct for pct, mw in lut.tuples if mw >= max_mw),
            float(lut.tuples[-1][0]),
        )
        return float(saturating_pct), True

            from importlib.resources import files as _resource_files


            def load_bundled_default_luts() -> dict[int, PowerLut]:
                """Parse all `default_<wavelength>nm.lut` files bundled with neuroseq.

                Returns ``{wavelength_nm: PowerLut}``. Currently ships a default for
                1100 nm only; 940 nm and 1030 nm fall back to "no LUT" until the
                user provides one.
                """
                bundled: dict[int, PowerLut] = {}
                lut_dir = _resource_files("neuroseq.resources.syscon_luts")
                for entry in lut_dir.iterdir():
                    name = entry.name
                    if not name.startswith("default_") or not name.endswith("nm.lut"):
                        continue
                    try:
                        wavelength_nm = int(name[len("default_") : -len("nm.lut")])
                    except ValueError:
                        continue
                    bundled[wavelength_nm] = parse_power_lut_text(entry.read_text())
                return bundled


            DEFAULT_POWER_LUTS: dict[int, PowerLut] = load_bundled_default_luts()


            def resolve_power_lut(
                project_luts: dict[int, PowerLut],
                wavelength_nm: int,
            ) -> tuple[PowerLut | None, bool]:
                """Resolve the LUT to use at export time.

                Returns ``(lut, is_user_override)``: the project's LUT takes
                precedence, falling back to the bundled default. The boolean is
                True when the project overrode the default — useful for the UI
                status label.
                """
                if wavelength_nm in project_luts:
                    return project_luts[wavelength_nm], True
                return DEFAULT_POWER_LUTS.get(wavelength_nm), False

────────────────────────────────────────────────────────────────────────────────────────────
OUT OF SCOPE — explicitly NOT in this patch
────────────────────────────────────────────────────────────────────────────────────────────

  - Multi-spot LUTs. The user's example file is called "1100nm 1 spot"; SysCon
    has separate LUTs for stimulating N spots simultaneously (since the SLM
    splits power across spots). For now, the project bundles ONE LUT per
    wavelength regardless of simultaneous-spot count. A follow-up can key LUTs
    by `(wavelength_nm, n_spots)` and pick at export time.
  - Writing `.lut` files back to disk. NeuroSeq only READS the LUT for inverse
    lookup; the canonical `.lut` lives in SysCon's hardware config.
  - Validating the `.lut` hash line. We ignore it — SysCon-internal.
  - Per-burst intensity inside a merged TTL pulse. The merged pulse takes the
    MAX intensity of any overlapping shape. If you ever need per-burst power
    modulation, that requires splitting `pulse_intervals` back into raw
    segments — too invasive for this patch.
  - UI for editing a loaded LUT inside NeuroSeq. The expectation is: user loads
    a fresh `.lut` from disk when SysCon's hardware re-calibrates.
