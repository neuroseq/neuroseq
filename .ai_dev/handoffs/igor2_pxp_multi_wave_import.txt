HANDOFF: Keep Igor2 import dialog open for multi-wave .pxp imports
===================================================================
Branch: import_igor2
Repo:   /mnt/live3/svintila/neuroseq
Date:   2026-04-20


PROBLEM
-------
When a user opens an Igor Packed Experiment (.pxp) via the Igor2 import
dialog, the file typically contains many 1-D waves (60+ in our reference
file `251118_0.pxp`). Today, as soon as the user clicks *Import* for one
wave, the dialog calls `self.accept()` and closes. To import a second
wave from the same file the user must reopen the dialog, reselect the
file, and wait for the full packed-experiment scan again.

For .pxp files this is clearly the wrong UX — the file is already scanned,
the wave picker is already populated, and the user will typically want to
import several waves from the same experiment back-to-back.

For .ibw and .csv there is only ever one wave per file, so accept-and-close
after a successful import remains correct.


TASK OVERVIEW
-------------
Change `igor_import_dialog.py` so that:

- For .pxp files: after a successful import, the dialog STAYS OPEN. The
  user can select and import additional waves from the same packed
  experiment without reloading the file. A "Close" button replaces the
  "Cancel" button once at least one wave has been imported, so closing
  the dialog still triggers the caller's post-accept hooks (project
  update + stim combobox switch).
- For .ibw and .csv files: unchanged — dialog still calls `self.accept()`
  on a successful import.

Scope is intentionally narrow: behaviour, buttons, and per-wave bookkeeping
inside `IgorImportDialog`. No changes to `importer_igor2.py`, no changes to
`gui.py`. Dialog tests must be updated to match the new flow; importer
tests are unaffected.

1e) Add a small helper method on the class:

        def _promote_cancel_to_close(self) -> None:
            """After the first successful .pxp import, rename Cancel to Close
            and route its signal to ``accept()`` so the caller's
            post-accept hooks (project refresh, combobox switch) still run.

            Called multiple times is safe: the reconnect is idempotent
            because disconnect()'s missing-signal case is caught silently."""
            if self.cancel_button.text() == "Close":
                return
            self.cancel_button.setText("Close")
            try:
                self.cancel_button.clicked.disconnect(self.reject)
            except (TypeError, RuntimeError):
                # Already disconnected (e.g. after unit-test monkeypatching)
                # — the connect below is the only thing that matters.
                pass
            self.cancel_button.clicked.connect(self.accept)

2b) Add a new test that exercises the full multi-wave flow end-to-end.
    Place it immediately after the existing
    `test_igor_import_dialog_warns_when_pxp_records_are_skipped`:

        def test_igor_import_dialog_stays_open_for_multiple_pxp_imports(
            tmp_path: Path,
            qtbot: QtBot,
            monkeypatch: pytest.MonkeyPatch,
        ) -> None:
            """Two waves from the same .pxp must be importable without
            reopening the dialog."""
            from neuroseq.importer_igor2 import IgorWave

            pxp_path = tmp_path / "multi.pxp"
            pxp_path.write_bytes(b"fake")

            wave_a = IgorWave(
                name="WaveA",
                values=np.array([1.0, 2.0, 3.0], dtype=np.float32),
                source_dt=0.001,
                units="pA",
                axis_units="s",
                source_format="ibw",
            )
            wave_b = IgorWave(
                name="WaveB",
                values=np.array([4.0, 5.0, 6.0], dtype=np.float32),
                source_dt=0.001,
                units="pA",
                axis_units="s",
                source_format="ibw",
            )
            fake_waves = {"root/WaveA": wave_a, "root/WaveB": wave_b}

            monkeypatch.setattr("neuroseq.igor_import_dialog.is_pxp_file", lambda _: True)
            monkeypatch.setattr(
                "neuroseq.igor_import_dialog.load_igor_pxp_file",
                lambda _: IgorPxpLoadReport(waves=fake_waves, skipped=[]),
            )

            project = Project()
            dialog = IgorImportDialog(project)
            qtbot.addWidget(dialog)
            dialog.show()
            qtbot.waitUntil(lambda: dialog.isVisible())
            dialog._load_file(str(pxp_path))

            # Select and import the first wave.
            items = [
                dialog.pxp_wave_list.item(i)
                for i in range(dialog.pxp_wave_list.count())
            ]
            assert {it.text() for it in items} == {"root/WaveA", "root/WaveB"}
            dialog.pxp_wave_list.setCurrentItem(
                next(it for it in items if it.text() == "root/WaveA")
            )
            assert dialog.loaded_wave is wave_a
            assert dialog.import_button.isEnabled()
            dialog._import_file()

            # Dialog stayed open; WaveA marked imported; WaveB still selectable.
            assert dialog.isVisible()
            assert dialog.cancel_button.text() == "Close"
            wave_a_item = next(
                it for it in (
                    dialog.pxp_wave_list.item(i)
                    for i in range(dialog.pxp_wave_list.count())
                )
                if "WaveA" in it.text()
            )
            assert wave_a_item.text().startswith("✓ ")
            assert not (wave_a_item.flags() & QtCore.Qt.ItemFlag.ItemIsSelectable)
            assert "WaveA" in project.stim_arrays

            # Select and import the second wave.
            wave_b_item = next(
                it for it in (
                    dialog.pxp_wave_list.item(i)
                    for i in range(dialog.pxp_wave_list.count())
                )
                if "WaveB" in it.text()
            )
            dialog.pxp_wave_list.setCurrentItem(wave_b_item)
            assert dialog.loaded_wave is wave_b
            # Name field was cleared after the first import, so auto-populate
            # should have re-filled from WaveB.
            assert dialog.new_name_edit.text() == "WaveB"
            dialog._import_file()

            assert dialog.isVisible()
            assert "WaveB" in project.stim_arrays
            assert dialog.selected_stim_name == "WaveB"

            # Close via the renamed button — caller sees Accepted.
            with qtbot.waitSignal(dialog.finished, timeout=1000):
                dialog.cancel_button.click()
            assert dialog.result() == QtWidgets.QDialog.DialogCode.Accepted

NOTES / GOTCHAS
---------------
- The dt-remap confirmation inside the "Import into existing stim array"
  branch calls `self.project.update_stim_array_properties(...)` which
  permanently changes the target stim's dt. This is current behaviour
  and unchanged by this handoff; do not alter it.

- The `selected_stim_name` field is overwritten on each successful
  import, so after multiple imports the caller (`gui.py:882`) will
  switch the main-window combobox to the LAST imported wave. This is
  the desired behaviour — the user's focus naturally follows what they
  just worked on.

- The `suppress_message_boxes` and `patch_b2w_exec_show` autouse
  fixtures described in CLAUDE.md already replace modal dialogs with
  non-blocking stubs, so the inline `last_import_label` is not needed
  to make tests pass — it is needed for the actual user-facing UX.

- `str.removeprefix` requires Python 3.9+; the project targets 3.10 so
  this is safe.

- Do not reset `self._had_successful_import` or `self._imported_pxp_keys`
  on Cancel→Close promotion: once the project has been modified, closing
  the dialog should always route through accept() so the caller's post-
  accept hooks run.

- Do not add a "Reset" or "Clear imported marks" button. If the user
  wants a clean slate they can simply close the dialog and reopen it.

- Pre-commit hooks (ruff + mypy + prettier + nbstripout) must pass.
