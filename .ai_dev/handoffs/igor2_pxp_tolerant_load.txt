HANDOFF: Tolerant Igor2 Packed Experiment (.pxp) loading
=========================================================
Branch: import_igor2
Repo: /mnt/live3/svintila/neuroseq
Date: 2026-04-20


PROBLEM
-------
Importing a real-world experimental .pxp through File → Import → Igor2 Wave
currently aborts with:

    TypeError: buffer is too small for requested array

before any waves are returned. The error originates *inside* igor2's own
`packed.load()` loop — specifically in
`igor2/binarywave.py:417` (`DynamicWaveDataField1.unpack`) — when a single
malformed wave record declares a shape/dtype whose byte size exceeds the bytes
igor2 actually read for that record. Because this happens record-by-record
inside the loader and propagates unchecked, **one bad record blocks the entire
file**.

Diagnostic on the reference failing file (see TEST DATA below):

    total records: 284
    parse-ok:      283
    parse-fail:      1   (record #55, WaveRecord, numDataBytes=1038,
                          header shape=[5], buffer=b'')

Root cause is upstream in igor2 0.5.13, so we cannot rely on a library fix in
the short term. Our importer must degrade gracefully: **skip the offending
record, log it, and import every wave we can still parse.** That single file
has ~200 usable experimental waves behind the one broken record — users lose
everything until we fix this.


TASK OVERVIEW
-------------
Replace our current `load_igor_pxp_file()` implementation so that it does NOT
call `igor2.packed.load()` directly. Instead, iterate the packed-experiment's
record stream ourselves (reusing igor2's lower-level primitives), catch
per-record unpack failures, and build the filesystem from only the records
that loaded successfully. Surface the number of skipped records to the user
in the import dialog.

Do NOT change the existing `.ibw`/`.csv` code paths. Do NOT touch unrelated
modules. This is a localised fix to the .pxp loader + a small UX addition in
the dialog.

Full spec context: .ai_dev/specs/igor2_pxp_import.md (still valid; this
handoff extends/corrects CHANGE 1).

1b) Replace the existing `load_igor_pxp_file()` entirely. New signature and
    body:

    def load_igor_pxp_file(path: str | Path) -> IgorPxpLoadReport:
        """Load all 1-D waves from an Igor Packed Experiment (.pxp) file.

        Uses a tolerant record-by-record loader: a single malformed wave
        record (e.g. igor2 0.5.x can raise ``TypeError: buffer is too small
        for requested array`` on some multidimensional / dependency-formula
        waves) is logged and skipped rather than aborting the whole load.

        Returns an :class:`IgorPxpLoadReport` whose ``waves`` dict maps
        slash-joined folder paths to :class:`IgorWave` objects, and whose
        ``skipped`` list enumerates records that could not be parsed.

        Raises ``ImportError`` if igor2 is not installed. Raises
        ``ValueError`` only if no importable 1-D waves survive.
        """
        path = Path(path)
        try:
            packed = importlib.import_module("igor2.packed")
            wave_record_module = importlib.import_module("igor2.record.wave")
            record_module = importlib.import_module("igor2.record")
            record_base = importlib.import_module("igor2.record.base")
            folder_module = importlib.import_module("igor2.record.folder")
            struct_module = importlib.import_module("igor2.struct")
            util_module = importlib.import_module("igor2.util")
        except ImportError as exc:
            raise ImportError(
                "Reading Igor Packed Experiment files requires the optional 'igor2' dependency."
            ) from exc

        WaveRecord = wave_record_module.WaveRecord
        RECORD_TYPE = record_module.RECORD_TYPE
        UnknownRecord = record_base.UnknownRecord
        UnusedRecord = record_base.UnusedRecord
        FolderStartRecord = folder_module.FolderStartRecord
        FolderEndRecord = folder_module.FolderEndRecord
        Structure = struct_module.Structure
        Field = struct_module.Field
        byte_order = util_module.byte_order
        need_to_reorder_bytes = util_module.need_to_reorder_bytes

        # Mirror the header struct used by igor2.packed.setup_packed_file_record_header.
        # Declared here so we stay independent of any private helpers in igor2.packed.
        def _make_header_struct(bo: str):
            hs = Structure(
                name="PackedFileRecordHeader",
                fields=[
                    Field("H", "recordType"),
                    Field("h", "version"),
                    Field("l", "numDataBytes"),
                ],
                byte_order=bo,
            )
            hs.setup()
            return hs

        PACKEDRECTYPE_MASK = 0x7FFF  # same mask igor2.packed uses

        records: list[object] = []
        skipped: list[SkippedPxpRecord] = []
        bo: str | None = None
        initial_bo = "="

        with path.open("rb") as fp:
            record_index = 0
            while True:
                header_struct = _make_header_struct(bo or initial_bo)
                header_bytes = fp.read(header_struct.size)
                if not header_bytes:
                    break
                if len(header_bytes) < header_struct.size:
                    # Malformed trailing bytes — stop parsing but keep what we have.
                    logger.warning(
                        "Truncated record header in %s at byte offset %d; "
                        "stopping after %d records.",
                        path.name, fp.tell() - len(header_bytes), record_index,
                    )
                    break

                header = header_struct.unpack_from(header_bytes)
                if header["version"] and bo is None:
                    reorder = need_to_reorder_bytes(header["version"])
                    bo = initial_bo = byte_order(reorder)
                    if reorder:
                        header_struct = _make_header_struct(bo)
                        header = header_struct.unpack_from(header_bytes)

                data = fp.read(header["numDataBytes"])
                if len(data) < header["numDataBytes"]:
                    logger.warning(
                        "Truncated record #%d in %s (wanted %d bytes, got %d); "
                        "stopping the packed-record scan.",
                        record_index + 1, path.name,
                        header["numDataBytes"], len(data),
                    )
                    break

                record_index += 1
                record_type = RECORD_TYPE.get(
                    header["recordType"] & PACKEDRECTYPE_MASK, UnknownRecord
                )
                try:
                    record_obj = record_type(header, data, byte_order=bo)
                except Exception as exc:  # pragma: no cover — exercised by integration test
                    logger.warning(
                        "Skipping malformed Igor packed record #%d (%s) in %s: %s",
                        record_index, record_type.__name__, path.name, exc,
                    )
                    skipped.append(SkippedPxpRecord(
                        record_index=record_index,
                        record_type=record_type.__name__,
                        reason=f"{type(exc).__name__}: {exc}",
                    ))
                    continue

                # Folder delimiters MUST NOT be dropped — the walk below relies on
                # balanced start/end pairs. If they ever fail to unpack (they are
                # tiny and simple, so this is extremely unlikely), we'd have to
                # stop here or risk misaligning the folder tree. We treat them as
                # fatal.
                records.append(record_obj)

                _ = (FolderStartRecord, FolderEndRecord, UnusedRecord)  # referenced for clarity / future use

        # Reuse igor2's own filesystem builder — it is module-private but stable
        # across the 0.5.x series, and reimplementing the name-collision/sysvar
        # handling here is error-prone.
        build_filesystem = getattr(packed, "_build_filesystem")
        filesystem = build_filesystem(records)

        waves: dict[str, IgorWave] = {}

        def _collect(dirpath: list[object], key: object, value: object) -> None:
            if not isinstance(value, WaveRecord):
                return
            parts = [
                seg.decode("utf-8", errors="ignore")
                if isinstance(seg, (bytes, bytearray))
                else str(seg)
                for seg in dirpath
            ]
            wave_name_str = (
                key.decode("utf-8", errors="ignore")
                if isinstance(key, (bytes, bytearray))
                else str(key)
            )
            parts.append(wave_name_str)
            path_key = "/".join(parts)
            try:
                igor_wave = parse_igor_binary_wave_data(
                    value.wave,
                    fallback_name=wave_name_str,
                )
            except ValueError as exc:
                # E.g. multi-dimensional waves: not an error, just not importable.
                logger.debug("Skipping wave %s: %s", path_key, exc)
                return
            waves[path_key] = igor_wave

        packed.walk(filesystem, _collect)

        if not waves:
            raise ValueError(
                f"No importable 1-D waves found in packed experiment file '{path.name}'"
            )

        return IgorPxpLoadReport(waves=waves, skipped=skipped)

NOTES / GOTCHAS
---------------
- `igor2.packed._build_filesystem` is module-private in igor2. We call it by
  attribute lookup (`getattr(packed, "_build_filesystem")`) rather than
  importing a private name with `from ... import _build_filesystem`. This is
  intentional: it keeps the attribute access explicit at the one call site and
  avoids polluting module-level imports with a private name that could break
  on a future igor2 upgrade. If it ever disappears upstream, the clearest
  alternative is to inline a copy of the 25-line `_build_filesystem`
  implementation — do NOT paper over it by calling `packed.load()` again.

- `packed.walk()` is a public symbol and is safe to keep using.

- Folder start/end records are treated as structurally load-bearing: if one
  ever fails to unpack, our loop currently still skips it (which would
  misalign the folder tree downstream). In practice these records are a few
  bytes long and have not been observed to fail in any of our fixture files.
  The logger.warning on a skipped FolderStartRecord/FolderEndRecord is a
  useful breadcrumb if this ever happens; no further handling is required
  until it does.

- Do NOT change the public `IgorWave` / `PreparedIgorWave` / `IgorImportReport`
  dataclasses — they are serialised-by-value through stim-array pipelines and
  are checked in downstream tests.

- Do NOT add retries, partial-bytes heuristics, or zero-padding fallbacks
  inside `parse_igor_binary_wave_data()`. Silent data fabrication in a
  scientific pipeline is unsafe; the tolerant loader above is strictly a
  per-record "skip on failure" mechanism, not a "repair on failure" one.

- Keep the new dataclasses and functions alphabetically-ish ordered within the
  existing file layout; don't reshuffle unrelated sections.

- Pre-commit hooks (ruff, mypy, prettier, nbstripout) must pass. Run
  `pre-commit run --all-files` before calling the task done.
