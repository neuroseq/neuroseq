loop_stim_array — Tile every stim array N times along the time axis, with optional periodicity-detect trim
============================================================================================================

Add a new toolbar action "Loop stim array" next to the existing
"Pad / Trim / Clear stim array" family in the stim editor. The action opens
a small dialog where the user enters an integer loop count N and optionally
clicks a "Detect period & trim" button before looping. On OK the dialog
multiplies every project stim array's time axis by N (literal np.tile-style
repetition), keeping all stim arrays time-aligned the same way Pad and Trim
already do.

Loop is a RESHAPE operation (it changes the time-axis length of the values
array), not a slice edit. The existing per-cell `StimArrayModifier` undo
machinery cannot represent reshapes — its `ReversibleAction` requires a
fixed shape (see `src/neuroseq/stim_array_modifier.py:14-42`). Loop must
therefore follow the same pattern as Pad/Trim: mutate the stim array values
in place via a new `Project.loop_stim_arrays(n_loops)` method, then call
`self.set_project(self.project, keep_undo_history=False)` to refresh the
view. Loop is consequently NOT Ctrl-Z-undoable — same as Pad/Trim today.

Files to change:
    src/neuroseq/project.py             (new method `loop_stim_arrays`)
    src/neuroseq/stim_editor.py         (new method `loop_stim_array`, new toolbar action)

Files to create:
    src/neuroseq/stim_loop_dialog.py    (`StimLoopDialog`, `_detect_period`)
    tests/test_stim_loop.py             (unit + qtbot tests)

────────────────────────────────────────────────────────────────────────────────────────────
BACKGROUND — how Pad and Trim work today
────────────────────────────────────────────────────────────────────────────────────────────

The toolbar actions for Pad (`stim_editor.py:214`) and Trim
(`stim_editor.py:256`) follow a fixed shape:

    1.  Open a `QInputDialog` for a duration in seconds.
    2.  Validate the input (positive float, doesn't exceed current length).
    3.  Call `self.project.pad_stim_arrays(total_time_seconds=...)` or
        `self.project.trim_stim_arrays(total_time_seconds=...)`.
    4.  Call `self.set_project(self.project, keep_undo_history=False)` to
        refresh the GUI and clear undo history.

Both project methods (`project.py:673` for pad, `project.py:691` for trim)
loop over every entry in `self.stim_arrays.values()` and resize that
StimArray's `.values` array, then call `self.update_limits()`. Time
alignment across stims is preserved because the operation is uniform.

Loop slots into the same pattern with `np.tile` as the per-stim primitive.

Add the method as a sibling of `pad_stim_arrays` (line 673) and

    def loop_stim_arrays(self, n_loops: int) -> None:
        """Tile every stim array's values along the time axis (axis 0).

        Each stim's `.values` array becomes ``np.tile(values, (n_loops, 1))``,
        keeping every stim array time-aligned the way pad/trim do.

        Raises
        ------
        ValueError
            If `n_loops` is less than 1.
        """
        if n_loops < 1:
            raise ValueError(
                f"n_loops must be >= 1, got {n_loops}"
            )
        if n_loops == 1:
            return
        for stim_array in self.stim_arrays.values():
            stim_array.values = np.tile(stim_array.values, (n_loops, 1))
        self.update_limits()

CHANGES — src/neuroseq/stim_loop_dialog.py (new file)
────────────────────────────────────────────────────────────────────────────────────────────

The dialog has three rows:

    1.  STATUS LABEL (read-only). Shows current length and the looped length:

            "Current stim length: 2000 ms (2000 samples) → after × 5 = 10000 ms"

        Updates live when the spinbox value changes and after the Detect-period
        button has trimmed the stim.

    2.  DETECT-PERIOD ROW. A `QPushButton` labelled "Detect period and trim"
        with a status caption to its right (initially empty).

        Tooltip on the button:
            "Find the smallest repeating block in the current stim and trim
            the array to one period. Loop then composes that with the
            multiplier."

        On click:
          - Pick the first stim array in `project.stim_arrays.values()` as
            the reference (all stims share the same time axis).
          - Run `_detect_period(reference.values)`.
          - If a period `p` is returned and `0 < p < T`:
              * Call `project.trim_stim_arrays(total_time_seconds=p * dt)`
                where `dt = reference.dt`.
              * Update the status caption to:
                    f"Trimmed to {p * dt * 1000:.1f} ms ({p} samples) — 1 period"
              * Refresh the dialog's main status label (current length).
          - If `_detect_period` returns `None`:
              * Status caption: "No periodic block detected; array unchanged."
              * Array left alone, no exception.

    3.  SPINBOX ROW. `QSpinBox` labelled "Number of repetitions". Range 1..1000,
        default 2, single-step 1. `QDialogButtonBox.StandardButton.Ok |
        Cancel` standard button row.

`exec()` returns `Accepted` when the user clicks OK. The dialog exposes a
read-only `loop_count` property the caller reads after `exec()`.

Skeleton:

    from __future__ import annotations

    import logging

    import numpy as np
    from qtpy import QtWidgets

    from neuroseq.project import Project


    def _detect_period(values: np.ndarray) -> int | None:
        """Return the smallest integer p in [1, T//2] such that the values
        array is exactly periodic with period p, or None if no such p exists.

        "Exactly periodic with period p" means
            values[i, :] == values[i + p, :]   for all 0 <= i < T - p
        and the array length T is a multiple of p.

        For float arrays the comparison uses `np.allclose` with rtol=0,
        atol=1e-6 (stim values are stored in float32, voltage scale is mV,
        so 1e-6 mV tolerance is well below any meaningful numerical drift).
        """
        T = values.shape[0]
        if T < 2:
            return None
        for p in range(1, T // 2 + 1):
            if T % p != 0:
                continue
            if np.allclose(values[: T - p], values[p:], rtol=0.0, atol=1e-6):
                return p
        return None


    class StimLoopDialog(QtWidgets.QDialog):
        def __init__(self, project: Project, parent=None):
            super().__init__(parent)
            self.setWindowTitle("Loop stim array")
            self.project = project
            self.logger = logging.getLogger(__name__)

            self.status_label = QtWidgets.QLabel(self)
            self.detect_button = QtWidgets.QPushButton(
                "Detect period and trim", self
            )
            self.detect_button.setToolTip(
                "Find the smallest repeating block in the current stim and "
                "trim the array to one period. Loop then composes that with "
                "the multiplier."
            )
            self.detect_caption = QtWidgets.QLabel("", self)
            self.spinbox = QtWidgets.QSpinBox(self)
            self.spinbox.setRange(1, 1000)
            self.spinbox.setValue(2)
            self.spinbox.setSingleStep(1)
            self.button_box = QtWidgets.QDialogButtonBox(
                QtWidgets.QDialogButtonBox.StandardButton.Ok
                | QtWidgets.QDialogButtonBox.StandardButton.Cancel,
                parent=self,
            )

            layout = QtWidgets.QVBoxLayout(self)
            layout.addWidget(self.status_label)
            detect_row = QtWidgets.QHBoxLayout()
            detect_row.addWidget(self.detect_button)
            detect_row.addWidget(self.detect_caption)
            detect_row.addStretch(1)
            layout.addLayout(detect_row)
            spin_row = QtWidgets.QHBoxLayout()
            spin_row.addWidget(QtWidgets.QLabel("Number of repetitions:", self))
            spin_row.addWidget(self.spinbox)
            spin_row.addStretch(1)
            layout.addLayout(spin_row)
            layout.addWidget(self.button_box)

            self.detect_button.clicked.connect(self._on_detect_clicked)
            self.spinbox.valueChanged.connect(self._refresh_status_label)
            self.button_box.accepted.connect(self.accept)
            self.button_box.rejected.connect(self.reject)

            self._refresh_status_label()

        @property
        def loop_count(self) -> int:
            return int(self.spinbox.value())

        def _reference_stim(self):
            if not self.project.stim_arrays:
                return None
            return next(iter(self.project.stim_arrays.values()))

        def _refresh_status_label(self) -> None:
            ref = self._reference_stim()
            if ref is None:
                self.status_label.setText("(no stim arrays)")
                return
            T = ref.values.shape[0]
            dt_ms = ref.dt * 1000.0
            current_ms = T * dt_ms
            n = self.loop_count
            looped_ms = current_ms * n
            self.status_label.setText(
                f"Current stim length: {current_ms:.1f} ms ({T} samples) "
                f"→ after × {n} = {looped_ms:.1f} ms"
            )

        def _on_detect_clicked(self) -> None:
            ref = self._reference_stim()
            if ref is None:
                self.detect_caption.setText("(no stim arrays)")
                return
            period = _detect_period(ref.values)
            if period is None or period <= 0 or period >= ref.values.shape[0]:
                self.detect_caption.setText(
                    "No periodic block detected; array unchanged."
                )
                return
            new_length_secs = period * ref.dt
            self.project.trim_stim_arrays(total_time_seconds=new_length_secs)
            self.detect_caption.setText(
                f"Trimmed to {new_length_secs * 1000.0:.1f} ms "
                f"({period} samples) — 1 period"
            )
            self._refresh_status_label()

The `T % p != 0` filter means a (2000, 13) Für Elise stim with 8 internal
240-sample cycles is NOT detected as period 240 (since 2000 % 240 ≠ 0).
That is INTENTIONAL — we only declare periodicity when it tiles cleanly. If
the user wants to detect cycles that don't divide T, they should Trim first
and then run Detect.

────────────────────────────────────────────────────────────────────────────────────────────
NON-GOALS
────────────────────────────────────────────────────────────────────────────────────────────

- PER-STIM LOOPING. All stim arrays loop together (same N), matching the
  uniform behaviour of Pad/Trim. Per-stim loop counts would require
  rethinking how the simulator handles unequal-length stims and is a
  separate spec.

- FUZZY PERIOD DETECTION. Current detector requires `T % p == 0` and uses
  `np.allclose(rtol=0, atol=1e-6)`. Approximate / autocorrelation-based
  detection is a separate feature.

- UNDO OF LOOP. Loop is a reshape; same as Pad/Trim, it is not undoable and
  the undo history is cleared via `keep_undo_history=False`. If
  undo-of-reshape becomes desirable, the right fix is to redesign
  `StimArrayModifier` to support shape-changing actions across the whole
  Pad/Trim/Loop family, not to retrofit Loop alone.

- LOOPING A SELECTED TIME RANGE. Out of scope; Loop tiles the entire values
  array. Users who want to loop a slice should Trim first.
